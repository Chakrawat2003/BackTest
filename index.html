ยังไม่ได้โหลดแท่งเทียน
ข้อจำกัดที่ควรรู้
นี่คือโปรแกรมจำลอง ไม่ใช่ระบบส่งคำสั่งจริง ผลย้อนหลังไม่รับประกันผลในอนาคต

• โหลดแท่งเทียน 1h แบบแบ่งหน้า REST สูงสุด 1,500 แท่งต่อคำขอ และอาจใช้เวลาตามจำนวนปี/ข้อจำกัด API
• Max history หมายถึงข้อมูลที่ Binance API คืนให้ได้ ณ วันที่เรียก ไม่ใช่การรับประกันว่ามีข้อมูลครบทุกช่วง
• SL/TP ใช้ High/Low ของแท่งเทียน; หาก SL และ TP ถูกแตะในแท่งเดียวกัน จะถือว่า SL เกิดก่อน (แบบระมัดระวัง)
• ไม่จำลอง Maintenance Margin / Liquidation อย่างละเอียด, slippage และ market impact จึงไม่ควรใช้แทนบัญชีจริง
• Funding rate จริงมีประวัติแยกตาม timestamp; รุ่นนี้ใช้ค่าคงที่ที่ตั้งเองในการคำนวณ backtest
